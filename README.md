## 📖 About the Project

DailyCore is a Full-Stack productivity application developed as an individual university project.

The Front-End provides a user-friendly interface for interacting with daily routines, tasks, and account functionality.

This repository contains the React application.

## ✨ Features

- User registration and login
- Routine and task management interfaces
- Integration with a REST API
- Responsive web interface
- Form validation and user feedback

## 🛠️ Tech Stack

| Category | Technologies |
|---|---|
| Library | React |

| Build Tool | Vite |

| Version Control | Git & GitHub |
| E2E Testing | Playwright |
| Deployment | Vercel |

## 🏗️ Application Structure

The Front-End communicates with the DailyCore Spring Boot Back-End through REST API endpoints.

The application separates user interface components from API communication and application logic.

## 🧪 Testing

End-to-end testing was performed using Playwright.

Additional quality checks included frontend performance analysis using Lighthouse.

## 🚀 Local Development

Requirements:

- Node.js
- npm

Clone the repository:

```bash
git clone https://github.com/barreirafds/DailyCoreFrontEnd.git
cd DailyCoreFrontEnd
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Configure the Back-End API address according to the project's environment configuration.
